## 📂 Proyectos destacados

### [Gestión de usuarios — ASP.NET Core MVC](https://github.com/FiorellaAguayo/Usuarios-CRUD-ASPNETCore-MVC)

Aplicación web para administrar usuarios mediante operaciones CRUD. Desarrollada con C#, ASP.NET Core MVC, Entity Framework Core y SQL Server.

### [Patitas Suaves — Sistema de adopciones](https://github.com/FiorellaAguayo/AdoptaGatitos-CSharp-AppWF)

Aplicación de escritorio desarrollada en C# y Windows Forms para gestionar adopciones de gatos, con registro de animales y adoptantes y funcionalidades diferenciadas según el rol del usuario.

### [Gestión de personas — JavaScript](https://github.com/FiorellaAguayo/ABMPersonas-HTML-CSS-JS-MapReduceFilter)

Aplicación web que permite administrar registros de personas, realizar búsquedas y aplicar filtros, ordenamientos y validaciones utilizando HTML, CSS y JavaScript.

### [Plataforma de películas — Codo a Codo](https://github.com/FiorellaAguayo/PlataformaDePeliculas-HTML-CSS-JS-CAC)

Proyecto frontend de una plataforma de películas y series, desarrollado con HTML, CSS y JavaScript.

[Ver demo](https://fiorellaaguayo.github.io/PlataformaDePeliculas-HTML-CSS-JS-CAC/)

### [Control de barrera — Arduino](https://github.com/FiorellaAguayo/ControlBarrera-CPP-Arduino)

Sistema de control de barrera desarrollado con Arduino y C++, que incorpora configuración de ángulos, control de apertura y cierre y validación mediante clave de seguridad.
