## 📂 Proyectos destacados

### [Gestión de usuarios — ASP.NET Core MVC](https://github.com/FiorellaAguayo/Usuarios-CRUD-ASPNETCore-MVC)

Aplicación web para administrar usuarios mediante operaciones CRUD. Desarrollada con C#, ASP.NET Core MVC, Entity Framework Core y SQL Server.

Aplicación de escritorio desarrollada en C# y Windows Forms para gestionar adopciones de gatos, con registro de animales y adoptantes y funcionalidades diferenciadas según el rol del usuario.
